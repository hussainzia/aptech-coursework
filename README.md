## 🚀 How to run

Most projects are plain HTML, CSS and JavaScript:

1. Download the repo (**Code → Download ZIP**) or clone it:
   ```bash
   git clone https://github.com/hussainzia/aptech-coursework.git
   ```
2. Open any `index.html` in your browser. For the best result, use the VS Code **Live Server** extension.

The PHP login system needs a local server such as XAMPP. See [its README](Aptech/php/login/README.md) for the steps.
